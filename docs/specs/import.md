# Lists: импорт из других менеджеров задач

Состояние: реализовано в ядре (`core/src/import.rs`), проверено тестами `core/tests/import.rs`; импорт 2Do дополнительно прогнан на настоящей резервной копии 2Do 4.19 для macOS. Источники: запрос автора проекта от 2026-10-05; разбор настоящей резервной копии; документация Todoist, Trello и Microsoft Graph (ссылки ниже).

## Назначение и границы

Перенести данные из другого менеджера одним файлом. Формат определяется по содержимому. Повторный импорт того же файла обновляет уже перенесённое и не создаёт дубликатов: идентификаторы вычисляются из идентификаторов источника.

Вход — в меню «Файл → Импорт…» на macOS, в настройках на Android, в боковой панели веб-интерфейса.

## Требования

- I1. **2Do**, файл `.2dodb` («Save a Copy…» или автоматические копии в `~/Library/Containers/com.guidedways.TodoMac/Data/Library/Application Support/Backups`). Это zip с базой SQLite `2do.db` и каталогом вложений. Переносятся: обычные списки с цветом, задачи с названием, заметкой, сроком (с временем), датой начала, приоритетом, тегами, выполнением, вложенностью, признаком проекта, ссылкой и файлами вложений.
- I2. Правило повтора из 2Do переносится целиком: «каждые N дней, недель, месяцев, лет» (так хранятся и готовые варианты 2Do), еженедельно по выбранным дням, «n-й или последний день недели месяца», отсчёт от даты выполнения, окончание на дату и после числа повторов. Задача с кодом повтора вне таблицы ниже получает тег `2do-repeat`, а отчёт называет число таких задач.
- I3. **Todoist**, CSV-шаблон проекта. Имя файла становится названием списка. Переносятся задачи с вложенностью (`INDENT`), описанием, комментариями (в заметку), приоритетом, метками `@label` и датой. Дата или повтор, записанные словами и не распознанные, добавляются в заметку как есть.
- I4. **Trello**, JSON доски. Колонки становятся списками «Доска: колонка», карточки — задачами, пункты чек-листов — подзадачами, метки — тегами. Архивные карточки и колонки пропускаются.
- I5. **Microsoft To Do**, списки с задачами в виде JSON, как их отдаёт Microsoft Graph (`todoTaskList` с вложенным `tasks`). Собственного экспорта у приложения нет; такой файл даёт, например, утилита Microsoft-To-Do-Export. Переносятся название, заметка, срок, начало, напоминание, важность, категории, выполнение, шаги и повторы, кроме «относительных» («второй вторник месяца»).
- I6. После импорта пользователь видит отчёт: сколько списков, задач и вложений перенесено и что перенести не удалось.
- I7. Файл неизвестного формата отклоняется с объяснением и ничего не меняет.
- I8. **2Do, имя вложения.** 2Do хранит имя вложения и его расширение раздельно: фотография записана как «Image» с расширением «jpg» рядом. Вложение получает имя с расширением: «Image.jpg». Имя, которое уже кончается этим расширением, не меняется; вложение без имени называется «attachment» с расширением.

## Что известно о форматах

2Do, по базе версии 4.19 для macOS. Кодировка установлена опытом 2026-10-05: через программный интерфейс 2Do (команды AppleScript `create_task`, `query_tasks`) созданы 37 пробных задач с известными свойствами, их значения прочитаны из базы, после чего задачи удалены. Восемь повторяющихся задач автора дополнительно сверены с тем, что о них сообщает само приложение.

- Списки — таблица `calendars`. Обычные списки имеют `listtype = 0`, «Входящие» — `isinboxcal = 1`, остальные значения `listtype` — служебные представления; умные списки отличаются непустым `smartsearch`; цвет — `colorhex`.
- Задачи — таблица `tasks`; `parent` — `uid` родителя.
- Срок: `duedate` — секунды Unix, полдень UTC нужного дня; значение около 6,4 млрд означает «нет даты». Время срока — отдельное поле `duetime`, число вида ЧЧММ (930 — это 09:30), 999999 — «без времени».
- Начало: `startdate` — секунды Unix, поля UTC которых равны местным дате и времени; полночь означает «без времени».
- Приоритет по шкале iCalendar: 1 — высокий, 5 — средний, 9 — низкий, 10 — нет.
- `tasktype`: 0 — задача, 1 — чек-лист, 2 — проект. Чек-лист переносится обычной задачей с подзадачами.
- Теги — поле `tags`: по восемь значений на тег через разделитель `_~|$$@$$|~_`, первое — название. Проверено на задачах с одним тегом; несколько тегов у одной задачи не встречались.
- Вложения — таблица `taskattachments`, файл лежит в `2DoBackupPayload/Attachments/<relativepath>`.
- Повтор:

| `repeattype` | `repeatvalue` | Правило |
|---|---|---|
| 1–127 | 1 | еженедельно по дням: сумма битов вс 1, сб 2, пт 4, чт 8, ср 16, вт 32, пн 64 |
| 256 | N | каждые N дней («каждый день» — N = 1) |
| 257 | N | каждые N недель |
| 258 | N | каждые N месяцев |
| 259 | N | каждые N лет |
| 260–266 | 1–5 или 6 | n-й (6 — последний) день недели каждого месяца; 260 — понедельник … 266 — воскресенье |

  `recurrence` = 2 — отсчёт от даты выполнения (1 — от срока). `recurrenceendtype`: 1 — до даты `recurrenceenddate`, 2 — осталось `recurrenceendrepeats` повторов.

Не проверено: `repeatvalue` больше 1 у еженедельного правила по дням (принято за интервал в неделях; интерфейс 2Do такое сочетание создать не дал), несколько тегов у задачи, форматы резервных копий 2Do для Android (`.2dobackup`, `.2dobundle`).

Todoist, Trello и Microsoft To Do реализованы по документации, на настоящих выгрузках не запускались:

- <https://www.todoist.com/help/articles/import-or-export-a-project-as-a-csv-file-in-todoist-YC8YvN>
- <https://developer.atlassian.com/cloud/trello/guides/rest-api/object-definitions/>
- <https://learn.microsoft.com/en-us/graph/api/resources/todotask?view=graph-rest-1.0>, <https://github.com/daylamtayari/Microsoft-To-Do-Export>

## Проверочные сценарии

`core/tests/import.rs`:

- I1, I2: `twodo_backup_brings_lists_tasks_subtasks_tags_and_attachments` — база со схемой настоящей копии; модульные тесты `twodo_repeat_codes` и `twodo_dates` в `core/src/import.rs` повторяют значения, записанные самим 2Do; служебные, умные и удалённые списки не переносятся; путь вложения, выходящий за пределы копии, игнорируется; повторный импорт не создаёт дубликатов.
- I8: `i8_twodo_attachment_gets_the_extension_kept_beside_its_name` — вложение «Image» с расширением «jpg» становится «Image.jpg» с типом JPEG, «План.jpg» остаётся как есть.
- I3: `todoist_csv_template`. I4: `trello_board_json`. I5: `microsoft_to_do_lists_json`. I7: `unknown_files_are_refused_with_a_reason`.
